# Netcatty Agent Notes

Create a note only when code, tests, and normal documentation cannot preserve a lasting decision. Search active notes for an existing owner before writing. Mechanical edits and local UI changes are exempt.

Use the lifecycle and format in `../../notes/README.md`. An implemented note states shipped reality in the present tense. If a new decision fully replaces an older one, preserve unique rationale before archiving or deleting it; keep partial supersessions cross-linked. Archived notes are frozen and are never edited, translated, or treated as current authority.

For a new note, run `git diff --check` and review inbound links. Keep the note focused on ownership, compatibility, security, durable behavior, alternatives, consequences, or required verification.
